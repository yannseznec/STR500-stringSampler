## STR-500

This is all of the code and build info for the STR-500 gestural granular synthesizer. 

It is a granular synthesizer built for the Daisy Seed which uses a salvaged Gametrak string controller to playback a recorded sample. 

Here you will find a Pure Data system for running on the Daisy Seed, a KiCad project with the schematic and PCB design for the instrument, and a folder of information about the physical build. Current working version is called v1.2, and as it stands includes updated code and KiCad (full details on the build are not yet updated).
