## STR-500

This is all of the code and build info for the STR-500 gestural granular synthesizer. Watch this video for some background on the project and to see the instrument in action: https://youtu.be/luxsUPbPhyk 

![a picture of a finished STR-500](build_notes_etc/pictures/STR500_finalbuild.jpg)

The STR-500 is a granular synthesizer built for the Daisy Seed which uses a salvaged Gametrak string controller to playback a recorded sample. [Watch this video](https://youtu.be/GELGBzM0ZOE) for information on how to hack the strings out of a Gametrak. 

Here you will find a Pure Data system for running on the Daisy Seed, a KiCad project with the schematic and PCB design for the instrument, and a folder of information about the physical build including drill outlines and laser cutting files for the enclosure. Current working version is called v1.2. 

The project website can be found [here](https://www.impracticaldevices.com/docs/devices/str500/).

You can purchase a fully built STR-500, an STR-500 DIY kit, or a bare STR-500 PCB on the [Impractical Devices store on Lectronz](https://lectronz.com/stores/impracticaldevices). If they are sold out you can join the waitlist there to be notified when things are back in stock.
